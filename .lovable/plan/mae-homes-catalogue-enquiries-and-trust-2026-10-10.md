## Priority 1 — Scalable, searchable property catalogue
### User experience
- Retain the home-page Featured Portfolio and its Lagos, Abuja, and Land filters; add a dedicated searchable catalogue reachable through Properties without adding another top-level menu item.
- Search by neighbourhood, city, property name, and listing reference; filter by sale/lease/off-plan, property type, price range, bedrooms, and land size. Offer clear results counts, reset, sorting, empty states, and pagination.
- Expand each verified property into a shareable detail page with multiple real photos, gallery navigation, description, amenities, floor/land area, price and payment period, availability, documentation status, and last-verified date. Keep the existing quick-view modal as the fast browsing option.
- Preserve enquiry context from either view: listing reference, name, city, and source page.
### Content safeguards
- Owner must confirm current sample names, prices, locations, beds, features, titles, and photo-to-property mapping before importing them as live inventory. Uploaded photos alone do not establish these facts.
- Never present a generic land image as documentary evidence; mark illustrative photos accordingly or replace with verified plot photography.
### Acceptance
Search/filter combinations and shareable URLs produce consistent results; modal and full detail show the same property; unavailable listings are clearly identified; no current anchor or city-filter path is lost.

## Priority 2 — Dependable enquiry and conversion journey
### User experience
- Replace the current alert-only consultation form with actual saved enquiries and delivery to an owner-approved recipient. Preserve direct phone, email, and property-prefilled WhatsApp links.
- Carry a selected listing or Maryland/article topic into the form; collect name, preferred contact, interest, optional budget/city, and message without forcing unnecessary fields.
- Add accessible labels, validation, submission progress, duplicate-submission protection, honest success/failure messages, and an enquiry reference. Confirm receipt only after saving; do not claim an email was delivered just because a notification was queued.
- Provide an owner-only enquiry list with new/contacted/closed status and notification delivery status. Define retention and consent copy with the owner. Agree a response-time promise before displaying one.
### Acceptance
A submitted enquiry survives refresh, appears to the authorised owner, retains its property/topic context, and reports notification failures accurately. Invalid or failed submissions never show false success. Public visitors cannot read other enquiries.

## Technical implementation and release safeguards
- Activate **Lovable Cloud only after this plan is approved**, for managed listing records, photo storage, enquiries, and owner access. No activation is part of the completed logo change.
- Use TanStack routes for catalogue, property details, and articles; keep existing section anchors and filter deep links compatible. Use the existing design tokens and controls; split the large home-page file into focused modules only as needed, without redesigning working sections.
- Enforce public access only to published listings/articles and submission-only enquiry access; keep enquiry reads and editing owner-restricted. Validate input on the server, protect submissions against abuse, and keep secrets out of browser code.
- Deliver real WebP/AVIF size variants with picture/srcset and explicit dimensions; `sizes` alone does not generate smaller images. Lazy-load below-the-fold editorial and gallery images and preserve the hero's loading priority. Never upscale screenshots or crop away essential quote text.
- Add distinct metadata to each new content page, absolute canonical links, and sitemap entries on the live domain. Review the current relative canonical/Open Graph URL and incomplete sitemap base URL during this phase; only use absolute social-image URLs that correspond to displayed content.
- Before each release, test desktop/mobile layout, logo legibility, three-item menu, active highlighting, smooth scrolling, city/land filters, all legacy property hashes, gallery/modal closing and focus, contact links, enquiry failures/success, permissions, image loading, and console errors. Diagnose existing filter-hash timing and small-screen navigation limitations before extending them; do not silently redesign them in the brand update.
- Release in order: verified content/data inventory → catalogue → enquiry delivery → trust articles. Review each phase and retain a rollback point before moving on.
